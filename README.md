# FEELINGLOW# FEELINGLOW Profile Maker

FLOWGLOWをお祝いするイベント「FEELINGLOW」をイメージして、新規デザインで作成したプロフィールメーカーです。

## 入力項目
1. 名前
2. 推しメンバー
3. プロフィール画像
4. 好きな曲／リクエスト曲（最大4曲）
5. フリースペース

イベント名「FEELINGLOW」は固定表示です。

## 機能
- 入力内容をリアルタイムでプレビュー
- 1000×1414px PNGで保存
- PC / スマートフォン対応
- プロフィール画像はブラウザ内のFileReaderで読み込み
- 外部サーバーへの画像アップロード処理なし
- 外部ライブラリ不要（HTML 1ファイルで動作）

## 使い方
`index.html` をChromeまたはEdgeで開いてください。

## GitHub Pages
この `index.html` をGitHubリポジトリのルートへ配置し、GitHub Pagesを有効にすると公開できます。
